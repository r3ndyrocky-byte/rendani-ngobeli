# Rendani Ngobeli — Web Developer Portfolio

Personal business website for **Rendani Clive Ngobeli**, a web developer in Pretoria who builds mobile-friendly websites, WhatsApp ordering catalogues and simple enquiry automations for small businesses.

**Live site:** https://r3ndyrocky-byte.github.io/rendani-ngobeli/

## What's on the site

- **Home** – who I am, what I do and how to reach me
- **About** – background, qualifications and key strengths
- **Services** – six services with delivery times
- **Work** – projects and challenges
- **Availability and location** – weekly hours, start date, remote/hybrid/on-site
- **Rates** – packages and hourly, daily and monthly pricing in ZAR
- **Why hire me** and **Contact** – WhatsApp, email, LinkedIn and a validated contact form

## Built with

- Hand-written HTML, CSS and JavaScript in a single file (no frameworks or build step)
- Responsive, mobile-first layout using CSS Grid and Flexbox
- Inline SVG icons (Lucide, ISC licence) and Google Fonts (Poppins, Inter, JetBrains Mono)
- Accessible navigation (`aria-expanded`), labelled form fields and reduced-motion support
- Hosted free on GitHub Pages

## Run it locally

Download `index.html` and open it in any browser.
